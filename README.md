# Python Crash Course (Persian)

A beginner-friendly **Python** course in **Persian (Farsi)** designed to help absolute beginners learn Python from scratch through simple explanations, practical examples, and hands-on exercises.

Whether you're a student, self-learner, or someone starting your programming journey, this repository will guide you step by step.

## 📚 Course Content

Current lessons:

- ✅ Variables
- ✅ Strings
- ✅ Numbers
- ✅ Input

More topics will be added regularly, including:

- Numbers
- Lists
- Tuples
- Dictionaries
- Sets
- Conditional Statements
- Loops
- Functions
- Modules
- Object-Oriented Programming (OOP)
- File Handling
- Error Handling
- And much more...

## 🎯 Who is this course for?

This course is suitable for:

- Complete beginners
- Students

- Teachers looking for simple teaching materials
- Anyone interested in learning Python in Persian

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/Mostafa-Modaberi/python-crash-course-fa.git
```

Navigate to the project directory:

```bash
cd python-crash-course-fa
```

Run any lesson:

```bash
python 01-variables/variables.py
```
